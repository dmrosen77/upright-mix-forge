Mix recipe for Snapmaker Orca

SlotBlendStripesCycle patternMixArea
  1. In Snapmaker Orca start a new project (empty plate) with the U1 and your 4 filaments in slots 1–4, then File → Import the 3MF (don't Open it). The mixes above arrive in Color Mixing as slots 5, 6, … and each part is already assigned.
  2. Check the Color Mixing list matches the table (slot numbers and Cycle patterns). If you'd already added mixes, or imported onto a plate with objects, the file's mixes aren't applied: untick Include mix definitions, set First free mix slot, add the Cycle Mixes by hand, and re-export.
  3. Pick your real filament profile (e.g. PLA) for slots 1–4.
  4. Set the layer height to 0.08 mm (first layer too, if you can) and leave Subdivide Mix Layers off.

Swatch card & calibration

Print a card of real mixes, photograph it, and the predictions above switch to your measured colors. Uses the same layer height, layers per row, column width, base filament and slot colors as the plaque.
